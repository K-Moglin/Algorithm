自走棋战斗系统

6x6的六边形格子作为棋盘，有若干棋子，每个格子最多一个棋子，分为攻击和防御两个阵营

棋子属性
HP：生命值
ATK：攻击力
DEF：防御力
SPD：攻击速度
RNG：攻击范围

要求：
回合制：战斗按帧进行，每帧棋子按照攻击速度从高到低进行行动
目标选择：棋子每回合行动时，在所有存活敌方中选择最近的目标
距离：格子间的距离
行动：根据与目标的距离决定攻击还是移动
攻击：若目标在攻击范围内进行攻击。被攻击的棋子死亡后，同帧后续行动的棋子会感知到这一变化
     伤害算法（ATK x ATK / (ATK + DEF_target)）整除向下取整
移动：若目标不在攻击范围，则向目标移动一格，需要注意格子是否被其他棋子占据，棋子移动到所有合法相邻格子中
     离目标最近的位置，若多个位置距离相同则优选编号最小
即使：HP<=0立刻死亡
胜负：每一帧结束进行检查，有一方全部死亡则另一方获胜，若100帧后没有结束则平局
方向：六边形 6个相邻方向编号（0，5）：右上，右，右下，左下，左，左上
六边形坐标系：使用offset坐标，奇数行向右偏移

输入：
第一行，N,M,代表进攻和防守棋子个数
N + M行 COL,ROW,HP,ATK,DEF,SPD,RNG 棋子属性

输出：
胜利方 攻方 1 防守 0 平局2
并输出结束帧
